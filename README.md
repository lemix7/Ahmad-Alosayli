# React + TypeScript + Vite + Tailwind CSS

A clean, modern React starter configured with **React 18**, **TypeScript**, **Vite**, and **Tailwind CSS**.

## 🚀 Available Scripts

### `npm run dev`
Starts the local development server with Hot Module Replacement (HMR).
```bash
npm run dev
```

### `npm run build`
Type-checks with `tsc` and compiles an optimized production bundle into the `dist/` directory.
```bash
npm run build
```

### `npm run preview`
Locally preview the production build.
```bash
npm run preview
```
